# MALS - Modern Advanced Living Solutions

## Project Overview

MALS is a cutting-edge technology startup dedicated to transforming urban environments through intelligent, sustainable, and connected infrastructure solutions. This website showcases our smart city innovations designed to enhance quality of life while reducing environmental impact.

## Website Structure

### Homepage (index.html)
- **Hero Section**: Compelling headline "Smart Infrastructure for Modern Cities" with call-to-action buttons
- **About Section**: Comprehensive company overview including mission, vision, and core values
- **Navigation**: Sticky header with smooth scrolling navigation

### Solutions Page (solutions.html)
- **Our Innovations**: Detailed showcase of three flagship products:
  - Smart Lighting Pole with solar power and motion sensors
  - Smart Street Trash Bin with automated features
  - Smart Public Bench with charging capabilities
- **Future Ambitions**: Expansion plans for smart waste management and IoT integration

### Projects Page (projects.html)
- **Project Showcase**: Six diverse smart city projects with status tracking
- **Project Categories**: Urban lighting, waste management, public amenities, and environmental monitoring
- **Status Indicators**: Active, completed, and planned projects

### Team Page (team.html)
- **Management Team**: Executive leadership profiles
- **Technical Team**: Engineering and development specialists
- **Support Team**: Administrative and operational staff
- **Professional Bios**: Education, experience, and expertise areas

### Contact Page (contact.html)
- **Interactive Contact Form**: Data validation and submission handling
- **Company Information**: Address, email, phone, and social links
- **Map Integration**: Visual location indicator

## Key Features

### Design Philosophy
- **Dark Theme**: Modern, futuristic aesthetic with dark backgrounds
- **Color Scheme**: Primary red (#e63946) and white (#ffffff) accents on dark base (#0b0f14)
- **Typography**: Montserrat font family for clean, professional appearance
- **Responsive Design**: Mobile-first approach with breakpoints for all screen sizes

### User Experience
- **Smooth Animations**: CSS transitions for hover effects and page interactions
- **Sticky Navigation**: Persistent header with blur effect for modern feel
- **Card-Based Layout**: Consistent design patterns across all sections
- **Professional Imagery**: High-quality Unsplash images for visual appeal

### Technical Implementation
- **HTML5 Semantic Structure**: Proper use of header, main, section, article, and footer elements
- **CSS3 Modern Features**: CSS Grid, Flexbox, custom properties (variables), backdrop-filter
- **JavaScript Functionality**: Dynamic year in footer, form validation, interactive elements
- **Performance Optimized**: Efficient CSS with minimal JavaScript for fast loading
